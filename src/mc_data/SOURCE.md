# Minecraft runtime data

Schemora fetches raw JSON files from
[PrismarineJS/minecraft-data](https://github.com/PrismarineJS/minecraft-data/tree/8ffb321c74cffe779acf5c447d08c473c4c291d7)
at commit `8ffb321c74cffe779acf5c447d08c473c4c291d7`. 

Data is limited to Java 1.13 and above to align with modern data formats.

## Visual assets

The official [Mojang version manifest](https://piston-meta.mojang.com/mc/game/version_manifest_v2.json) is used to identify versions to extract visual assets from via the officially hosted .jar file.
